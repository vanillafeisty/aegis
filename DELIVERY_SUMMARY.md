## 💡 Pro Tips

1. **Keep Local Machine Running**
   - LinkedIn automation requires local Playwright
   - Run backend on local machine 24/7
   - Or use Zapier webhooks as fallback

2. **Session Cookie Expiration**
   - LinkedIn cookies expire every 30-60 days
   - Set calendar reminder to refresh
   - Get fresh cookie from Chrome DevTools

3. **Groq API Free Tier**
   - 30 requests/minute limit
   - Free tier is generous
   - Perfect for personal automation
   - Upgrade if you hit limits

4. **Gmail App Passwords**
   - Use 16-character App Password (not regular password)
   - Enable 2-Factor Authentication first
   - Don't share this password

5. **Zapier Integration**
   - Use HTTP streaming for large responses
   - Set up webhooks for real-time triggers
   - Test workflow IDs before production
