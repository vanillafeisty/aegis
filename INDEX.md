## 🚀 Quick Commands Reference

```bash
# Extract and run (fastest!)
unzip aegis-complete.zip
cd aegis-complete
./start.sh              # Mac/Linux
start.bat              # Windows

# Open in browser
# http://localhost:3000

# Stop services
# Press Ctrl+C in terminal

# Manual backend start
python app.py

# Manual frontend start (in frontend/ directory)
npm run dev

# Run tests
python test_api.py
npm test

# Build for production
cd frontend
npm run build
```
